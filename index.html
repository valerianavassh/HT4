Calculadora de Ecuación Cuadrática

¿Qué es una ecuación cuadrática?

Es una ecuación con la forma: ax² + bx + c = 0

Fórmula General

x = (-b ± √(b² - 4ac)) / 2a

a: Coeficiente cuadrático | b: Coeficiente lineal | c: Término independiente

El Discriminante (D)

Se calcula como: D = b² - 4ac

  • D > 0: Dos soluciones reales.
  • D = 0: Una solución real.
  • D < 0: Dos soluciones complejas.

Ejemplo Resuelto

x² - 5x + 6 = 0 (a=1, b=-5, c=6)

Resultado: x₁ = 3, x₂ = 2
